# LangChain Conquest

A gamified, source-grounded course from zero to hero: 42 realms across 10 provinces, from your first chat model through LangChain agents, LangGraph, Deep Agents, LangSmith evals and deployment, integrations and MCP, and Google ADK, to the four loops of loop engineering.

- Read each realm's briefings, then pass its siege (quiz) to conquer it and unlock the next.
- Every briefing links to the official docs or the authors' own posts; the Codex at the bottom lists all sources.
- Progress is saved in your browser (localStorage).

**Play:** https://mosaddek2020.github.io/langchain-conquest/

Code blocks marked "from the docs" are taken from official documentation; blocks marked "Sketch" are illustrative and worth checking against the docs for your package versions.
